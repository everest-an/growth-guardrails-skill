# Playbook:可借鉴策略清单、红线对照、自查 Checklist、输出模板

> 从 ABP(白帽被动分发 + B 端变现)与 360(激进获客)案例中提炼。
> 所有策略均给出"合规变体";标注 🚫 的为禁止做法(附法规依据,见 compliance.md)。

---

## 一、可借鉴(合规)策略清单

### S1. 家族产品交叉引流(360 的合规变体)
- 原始:装安全卫士 → 自动带出全家桶(默认勾选 + 链式安装)。
- **变体**:装 A 后,在**结果页/首次运行页**展示 B,CTA 为明确的 opt-in 按钮("立即使用" / "暂不需要"),**默认不勾选、可一键跳过、跳过即永不再提示**(或低频再提醒)。
- 转化杠杆:把"推荐理由"做成真实价值对比("B 与 A 数据互通,登录即同步")。
- 依据:2018 京广深消委会后,腾讯 QQ/360 的整改模式即"取消默认勾选 → 用户自主勾选",行业已形成事实标准。

### S2. OEM / 渠道合作(Opera 的合规变体)
- 原始:Opera 与手机厂商/运营商签约预装 Opera Mini(2007 起,Motorola/Nokia/Samsung/T-Mobile 等);ABP 通过 Yandex 浏览器集成触达 2400 万用户。
- **变体**:与硬件/浏览器厂商签预装或默认集成协议,但必须满足:
  1. 中国 2023 通告:非基本功能软件**必须可卸载**,同一功能至多一个不可卸载;
  2. 显著披露预装事实与功能(独立于用户协议);
  3. 不注入广告、不做中间人(见 FTC Lenovo 教训);
  4. 首次使用给用户选择(参考欧盟 DMA 选择屏)。
- 收益:一台设备触达一位用户,成本远低于买量;风险:预装方审核、监管新规。

### S3. 商店推荐位 / 精选(ABP 的合规路径)
- 原始:ABP 靠真实质量 + 头部装机量拿到商店推荐,形成马太效应(300M 下载、50M MAU)。
- **变体**:打磨真实留存与好评率(核心指标:卸载率、周活/月活、商店评分),用自然增长数据触发商店算法推荐;配合媒体评测/榜单(如 PC World 百强)。
- 禁止:买量刷榜、虚假评分、蹭名伪装——商店处罚 + FTC/GDPR 双风险。

### S4. 默认选项优化(把默认留给用户利益)
- 原始(反例):360 把默认主页/搜索改为 hao360(反不正当竞争法第十二条)。
- **变体**:默认值的选择标准 = **"绝大多数用户会感谢这个默认"**:
  - 隐私保护默认开(拦截跟踪器/遥测);
  - 通知默认关,价值功能默认开(如自动备份、安全扫描);
  - 提供"推荐设置" vs "自定义设置"两种路径(选择架构的合规用法)。
- 依据:EDPB 强调 data protection by default(GDPR 第 25 条);DMA 要求默认设置可轻松更改。

### S5. 卸载挽留(360 的反面教材 + 合规变体)
- 原始(反例):藏卸载按钮("忍痛卸载"文案)、必填问卷、恐吓话术、自保进程残留回魂。
- **变体**:
  - 卸载页做**真实价值挽留**:展示用户真实数据("您已使用 730 天,拦截了 1.2 万次广告")——损失厌恶的**合规版**;
  - 询问原因(可选),提供**替代方案**(降级免费版、关闭广告、减少提醒)而非只有"确认卸载";
  - **一键到达卸载完成**,无任何二次拦截;卸载后清理干净(无残留 = 口碑资产)。
- 依据:FTC Lenovo 令要求"合理有效的卸载途径";卸载体验是用户记忆最持久的触点。

### S6. 首次运行引导(onboarding)
- 原始(反例):360 压缩弹"垃圾清理"诱导静默装极速版(火绒 2022 报告)。
- **变体**:首次运行用 3-5 个步骤让用户**主动发现并启用**附加功能("开启 X 可获得 Y",opt-in);每一步都有"跳过"。
- 关键:CTA 即功能本身,点下去用户知道会发生什么——这是 nudge 与 dark pattern 的分界线。

### S7. B 端变现的"默认受益"模式(ABP 商业模型)
- 原始:Acceptable Ads —— 用户默认拦截广告(受益),大广告主付费进白名单(月增 1000 万次曝光以上者付新增广告收入 30%,90% 免费)。
- **变体**(通用化):免费产品对用户默认给好处,对 B 端收"让你出现在用户面前"的钱(白名单/认证/合作位),但:
  1. 用户默认受益(不被骚扰);
  2. 白名单/合作内容**透明可查、一键关闭**;
  3. 不因收费降低审核标准("pay-to-play"是声誉自杀,ABP 十年反噬为证)。

### S8. 行为经济学杠杆(合规版)
| 杠杆 | 合规用法 | 禁用用法 |
|---|---|---|
| 默认偏差 | 把"用户利益项"设为默认(隐私/安全) | 默认勾选捆绑项 |
| 所有权效应 | 免费试用 + 数据迁移,让用户"拥有"再转化 | 预装不可卸载制造"既定事实" |
| 损失厌恶 | 卸载页陈述**真实**损失(数据/权益) | 虚构"卸载后失去安全防护" |
| 社会认同 | "已有 5000 万用户"真实数据 | 伪造评价/下载量 |
| 稀缺性 | 真实限时权益(如首月免费) | 虚假倒计时 |

## 三、合规自查 Checklist(交付前逐项打勾)

**安装/分发环节**
- [ ] 所有捆绑项默认**不勾选**(opt-in)
- [ ] 捆绑项有**显著提示**,不藏于 EULA/隐私政策
- [ ] 有**独立卸载/关闭方式**,无技术性阻碍
- [ ] 无静默安装、无后台下载、无注入系统进程
- [ ] 预装软件(如走 OEM)可卸载,符合 2023 通告
- [ ] 不检测规避其他安全软件

**弹窗/推广环节**
- [ ] 所有弹窗有显著"一键关闭",非计时关闭、非二次点击关闭、关闭后不复发
- [ ] 弹窗内容不恐吓、不虚假("高危漏洞""系统崩溃"类话术禁用)
- [ ] 广告内容标注"广告"字样(可识别性)
- [ ] 未经同意不向智能设备/车载等发送广告
- [ ] 开屏广告同样满足一键关闭

**默认设置环节**
- [ ] 未未经选择篡改主页/搜索/浏览器默认
- [ ] 默认设置可轻松更改(DMA 精神)
- [ ] "推荐设置"如实,不诱导违背意图

**卸载环节**
- [ ] 卸载入口显眼可达
- [ ] 挽留话术只陈述真实损失
- [ ] 卸载后无残留、无回魂、无"是否恢复"弹窗
- [ ] 卸载问卷可选填(无必填强制)

**数据/同意环节**
- [ ] 任何个人数据处理有明确主动同意(无预勾选)
- [ ] 拒绝同意不影响核心服务(个保法第十六条)
- [ ] 同意可撤回,撤回与同意一样容易
